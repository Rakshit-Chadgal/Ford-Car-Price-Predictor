# 🚗 Ford Car Price Predictor

A machine learning project that predicts the price of used Ford cars based on features such as model, year, mileage, transmission, fuel type, tax, MPG, and engine size.

## 📌 Overview

This project explores a real-world regression problem using Python and Scikit-learn. The dataset is cleaned, analyzed, preprocessed, and used to train machine learning models for predicting car prices.

## ✨ Features

* 🔍 Exploratory Data Analysis
* 🧹 Data cleaning & preprocessing
* 🔤 Categorical feature encoding
* 🤖 Machine learning regression
* 📊 Model evaluation
* 📈 Data visualization
* 🚗 Used Ford car price prediction

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Rakshit-Chadgal/Ford-Car-Price-Predictor.git
cd Ford-Car-Price-Predictor
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Then open the notebook inside the `notebooks/` directory.
